# 05 验证：真实存档批量回归（体积对比 + 全量测试）

关联 spec：#29（save-size-opt）

## 任务

用真实存档 `idle-save-2026-08-12.json`（318KB，schemaVersion 16，NG+3，phase infinite）验证两处压缩的实际效果，并确认全量回归。

## 验收标准

1. **体积对比**：存档加载（走 deserializeSave 存量压缩）→ 再序列化，对比前后体积：
   - automationHistory：563 条 → ≤ 12h 窗口 + 保底 50 条（预期 ~77 条）
   - generatedTargets：312 条已归档条目精简为白名单
   - 整体体积 318KB → ~183KB（省 ~42%）
2. **运行回归**：加载压缩后存档跑 tick，无异常；cooldown 判断、攻占/外交/探索归档继续工作。
3. **全量测试**：vitest 全绿 + `tsc --noEmit` 通过。
4. **UI 抽查**：探索/军事/外交归档折叠区名称与周目徽章显示正常（压缩前对照）。

## 约束

- 真实存档测试只读验证，不写回用户存档（用副本）。
- 若体积未达预期，记录实际数字并分析原因，不强行凑数。
