# 04 — 舰队防御闭环（自动迎击 + 软降级）

**What to build:** 核心价值切片——舰队的能源消耗换来真实的防御回报，且能源枯竭时系统优雅降级而非惩罚玩家：

- **在线自动迎击**：骚扰事件被选中且舰队战力 ≥ 骚扰强度时，不生成事件卡，直接结算为日志（威胁 −15，不扣军力——舰队代劳，成本即持续维护费）；战力不足时事件照常弹窗，但「军力击退」所需军力 = 残余强度（`max(50, strength − fleetPower)`），hint 与结算口径一致。
- **软降级**：每 tick 能源结算后判定——能源 ≥ 总维护费则扣费、舰队运转；不足则**不扣费**、舰队停摆（自动迎击失效、骚扰退回手动弹窗、战力归零）；恢复供能后下一 tick 自动重启。UI 显示停摆警示。
- **离线同口径**：离线维护费整段硬扣（可为负、回归 clamp 0，同恒星阵列口径）；离线骚扰自动迎击优先消耗舰队战力（够强自动击退不扣军力），不足回退现有"军力击退/按无视扣资源"，30% 封顶不变。
