# 01 — 扩展统一数值展示契约

**What to build:** 建立统一的用户可见数值格式化能力，支持固定两位小数、中文大数单位、明确舍入、特殊值、业务单位和复合值；时间、日期、倒计时、版本号和编号继续使用自然格式。旧展示调用在迁移完成前保持可用。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 固定两位小数，使用十进制定点四舍五入，第三位为 5 时远离零
- [x] 支持零、负数、正负无穷和 NaN 的约定展示
- [x] 沿用每四位一档的中文大数单位，10000 起启用并正确处理舍入进位
- [x] 未缩写数字保留千位分隔符，小数点使用 `.`, 单位紧邻数值
- [x] 支持速率 `/秒`、百分比 `%`、倍率 `倍` 和每个独立值各自携带单位
- [x] 覆盖 9999/10000、负数、极小值、进位、无穷和 NaN 等边界测试
- [x] 证明内部计算、排序、存档和数据格式不受影响
