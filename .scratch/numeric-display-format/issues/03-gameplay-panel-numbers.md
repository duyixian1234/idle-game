# 03 — 迁移玩法面板数值

**What to build:** 将建造、科技、外交、军事、探索、舰队、征服、奖励和新周目等主要玩法面板中的资源、成本、战力、倍率、百分比和进度迁移到统一展示契约，让所有玩法面板遵循同一套比较规则。

**Blocked by:** 01 — 扩展统一数值展示契约

**Status:** resolved

- [x] 资源成本、产出、库存、战力和维护值统一固定两位小数并携带业务单位
- [x] 百分比统一使用两位小数和 `%`
- [x] 倍率统一使用两位小数和 `倍`
- [x] 进度、当前值/上限值和范围值遵循独立数值完整格式化规则
- [x] 所有玩法面板的禁用、购买、派遣、升级和比较行为保持不变
- [x] 更新相关单元测试和端到端断言，覆盖大数、负值、复合值和单位归属
