# 02 — 建筑系统与三资源

**What to build:** 三类建筑（采矿机/太阳能板/实验室）各自产出对应资源（矿物/能源/科技点），可购买与升级，成本随数量递增；至少一个"消耗能源提升矿物产出"的建筑，形成资源互锁。三类资源的产出循环完整可用，随存档保留。

**Blocked by:** 01

**Status:** resolved

## Answer

- 四类建筑数据驱动落地：采矿机（矿物）、太阳能板（能源）、实验室（科技点 0.5/s）、精炼厂（消耗 0.5 能源/s 产出 3 矿物/s，前置太阳能板）。
- 升级线：每级产出 +50%，成本 = 当前购买成本 ×4×1.6^level；未建造不可升级。
- 能源互锁：`productionReport` 以「本期能源产出 + 余额」为池，精炼厂产能按 可用/需求 比例打折，能源不为负。
- `buildings`/`upgrades` 双 map 随档；save 校验 upgrades 字段。
- UI 建造面板：锁定态（前置提示）、升级按钮、Lv 展示。
- 测试 32 个全绿（引擎 23 + 存档 4 + UI 5）；生产构建通过。
- 环境适配：vite `emptyOutDir: false`（沙箱 safe-delete 拦截目录清空）。

- [x] 各建筑产出对应资源，实时反映在资源条
- [x] 存在消耗能源提升矿物产出的建筑，资源互锁生效
