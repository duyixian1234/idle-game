# 05 — 日志流与随机事件

**What to build:** 中央日志流展示类型化消息（系统/叙事/事件/奖励，视觉区分）；轻量随机事件表（贸易商/陨石雨/虫族警报）按可控频率触发，各产生明确奖惩并写入日志。事件不打断玩家操作。

**Blocked by:** 02

**Status:** resolved

## Answer

- 类型化日志（system/story/event/reward/warning）新消息置顶，视觉区分（01 已就绪，本票强化）。
- `events.ts`：贸易商（矿物换科技点，交互）/ 陨石雨（立即获得矿物）/ 虫族警报（派遣花矿物 / 忽略扣 10% 矿物）三事件，权重表驱动。
- 触发：`nextEventAt` 到点触发一次并重排，均值间隔 90s ±50% 抖动；首触发 45s；超时 10 分钟未处理实例自动清理。
- `tick` 集成事件触发（rng 可注入），不打断资源结算；交互事件渲染为日志区事件卡片（选项按钮），处理结果写日志。
