# 05 — 日志流与随机事件

**What to build:** 中央日志流展示类型化消息（系统/叙事/事件/奖励，视觉区分）；轻量随机事件表（贸易商/陨石雨/虫族警报）按可控频率触发，各产生明确奖惩并写入日志。事件不打断玩家操作。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 日志按时间顺序展示，新消息置顶，不同类型有视觉区分
- [ ] 三类随机事件可触发：贸易商（矿物交易）、陨石雨（产出波动）、虫族警报（若不处理则扣减产出）
- [ ] 事件频率可控（均值间隔），触发不打断当前操作
- [ ] 事件结果正确变更资源并写入日志
