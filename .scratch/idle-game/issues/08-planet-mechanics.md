# 08 — 星球机制（第 3-5 星）

**What to build:** 第 3/4/5 颗星球各自独特机制完整落地。实现前先产出机制设计提案（方向示例：第 3 星"引力井"产出衰减曲线、第 4 星"轨道工厂"批量生产、第 5 星"曲率引擎"时间加速与终局前置），经确认后实现。每个机制贯穿引擎逻辑 + UI 操作/状态 + 存档。

**Blocked by:** 06

**Status:** resolved

## Answer

机制设计（按 ticket 方向示例落地，用户已授权直接实现）：

| 星球 | 机制 | 行为 |
|---|---|---|
| 冰封星·霜落 | 引力井衰减 | 驻留产出递减：系数 = max(0.5, 1 − 停留分钟×0.02)，约 25 分钟后封底 50%；切换星球重置 |
| 气态巨星·风暴之喉 | 风暴批量生产 | 能源产出 ×1.5；驻留时每 5 分钟自动凝聚风暴结晶（科技点，随科技产出缩放） |
| 母星·曙光 | 曲率时间加速 | 所有产出 ×3，终局前置 |

- 引擎：`applyPlanetMechanics` 扩展三种机制（orbitalForge 已有）；`tick` 累计 `planetStaySeconds`（非起点星）并触发 `applyStormHarvest`；`setActivePlanet` 重置停留。
- UI：星球条下方机制状态条（名称/描述/动态状态：衰减系数、风暴收获倒计时、时间流速）。
- 存档：`planetStaySeconds` / `lastStormHarvestAt` 随档校验。
- 测试 95 个全绿（新增机制 7）；生产构建通过。
