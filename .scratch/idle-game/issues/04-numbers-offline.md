# 04 — 大数字缩写与离线收益

**What to build:** 资源条以中文单位缩写显示大数字（万/亿/兆/京…）；离开页面后按真实时间差结算产出（8 小时封顶），回归时日志打印离线收益报告。离线结算使用注入时钟，可确定性测试。

**Blocked by:** 02

**Status:** resolved

## Answer

- `format.ts`：中文单位缩写万/亿/兆/京/垓…（每 4 位十进制一级，3 位有效数字），负数/∞ 兜底；资源条、成本、速率统一走该函数。
- `offline.ts`：`settleOffline(state, nowMs)` 注入时钟，按 lastTick 时间差结算产出，8 小时封顶；结算后 lastTick 更新避免重复结算；`formatDuration` 人类可读时长。
- main.ts：加载存档后先离线结算，收益 >0 时日志输出「离线收益」报告（各资源明细 + 封顶提示）。
- 测试 54 个全绿（format 7 + offline 6 + 引擎 23 + 存档 4 + UI 5）；生产构建通过。

- [x] 资源达到 1 万后显示缩写格式（1.2万），逐级至亿/兆及以上
- [x] 离线时间差结算正确，超过 8 小时部分不产生收益
- [x] 回归时日志输出离线收益报告（各资源明细）
- [x] 离线结算通过注入时钟的确定性单元测试
