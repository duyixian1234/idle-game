# 02 — 档案页：移除事件可解释性模块

**What to build:** 档案页不再显示事件自动配置、审计历史与迁移摘要三块内容，回归成就/声望/统计定位。玩家不再需要在档案页管理事件；自动处理的去向改由日志流承担（见 03 标注）。迁移说明不重复实现——现状存档迁移已把「【存档迁移】」条目写入日志流，首屏可见。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 删除档案页「事件可解释性」整块渲染（自动化配置 / 事件历史审计 / 迁移摘要三块）及其 main 层接线与相关 DOM 测试。
- [ ] `automationHistory` **只停渲染、保留引擎写入**：冷却判定（`ruleEligible` 按规则、fallback 按类别查最近 resolved 审计）依赖该账本，停写即冷却失效——不得删除 `recordAutomation` 调用。
- [ ] `migrationSummary` 字段保留在存档但不渲染（死数据无害，不升 schema）；迁移日志确认已在日志流（`【存档迁移】`条目），不做额外 UI。
- [ ] 删除后档案页无遗留半残区块（事件管理语义完全移出档案页）。
