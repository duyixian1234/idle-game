# 03 — 实现按类别配置的自动处理

**What to build:** 让玩家按事件类别配置自动处理策略，并让在线、离线和手动处理共享同一结算结果；低风险事件可安全兜底，高风险事件在不确定时暂停并通知。

**Blocked by:** 02 — 迁移现有事件与队列优先级

**Status:** ready-for-agent

- [ ] 每类事件可保存独立的自动处理策略、规则优先级、资源预算、风险阈值和冷却设置。
- [ ] 低风险事件支持接受/拒绝、最低收益、最低风险和资源上限等规则。
- [ ] 高风险、链式和首领事件支持备用选项；无可用规则或规则冲突时暂停并通知。
- [ ] 自动处理与手动处理调用相同结算管线，并产生一致的资源、能力、风险和后续事件结果。
- [ ] 自动结算记录选项、命中规则、规则原因、消耗、产出和失败/暂停原因。
- [ ] 引擎测试覆盖规则优先级、阈值、预算、冷却、兜底、冲突和审计记录。
