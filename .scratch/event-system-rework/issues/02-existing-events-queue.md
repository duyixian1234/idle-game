# 02 — 迁移现有事件与队列优先级

**What to build:** 将陨石雨、虫族警报、军事骚扰和舰队自动迎击接入统一事件管线，并让事件队列根据风险和处理模式区分普通事件与高影响事件。

**Blocked by:** 01 — 建立统一事件契约与贸易事件竖切片

**Status:** ready-for-agent

- [ ] 陨石雨、虫族警报、军事骚扰及舰队自动迎击均通过共享结算结果表达资源、能力和风险变化。
- [ ] 现有事件选项的资源不足、拒绝、忽略、舰队拦截和离线结算语义保持可验证且提示与扣费一致。
- [ ] 普通事件继续进入待处理队列，高风险事件具备优先级和强提醒/阻塞状态。
- [ ] 已知旧事件实例可迁移，未知或不兼容实例使用显式安全处理并记录迁移信息。
- [ ] 引擎测试覆盖所有现有事件、队列优先级、过期清理、离线结算和旧存档实例。
