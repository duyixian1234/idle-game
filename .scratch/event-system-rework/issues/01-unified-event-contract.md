# 01 — 建立统一事件契约与贸易事件竖切片

**What to build:** 让贸易事件通过新的统一事件契约、曲线计算和共享结算管线完成一次完整的生成、展示、手动结算、日志记录和存档迁移流程。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 事件定义支持主题、决策类型、风险等级、阶段/无尽资格和版本化曲线配置。
- [ ] 贸易事件使用统一的基础值、阶段/层数、风险和能力修正计算消耗与产出，并支持软上限。
- [ ] 事件实例固化结算值，手动结算返回资源变化和可解释的公式明细。
- [ ] 存档新增事件配置/版本字段，旧存档中的贸易事件可顺序迁移且不丢失进度。
- [ ] 引擎测试覆盖贸易事件生成、边界资源、固定 payload、曲线明细和迁移行为。
