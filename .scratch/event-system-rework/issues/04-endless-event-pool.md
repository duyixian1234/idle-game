# 04 — 增加无尽模式事件池、阶段链与首领事件

**What to build:** 让无限模式拥有独立且可持续扩展的事件体验：普通事件由基础事件、修饰和变体组合产生，阶段事件链与首领事件提供长期目标。

**Blocked by:** 02 — 迁移现有事件与队列优先级

**Status:** ready-for-agent

- [ ] 无限模式事件池支持主题、决策类型和风险标签组合，并包含至少一个代表性变体。
- [ ] 阶段事件链能根据无尽层数和前置结果推进，首领事件能产生明确的阶段结算与后续影响。
- [ ] 事件权重、阶段/层数倍率、风险倍率和能力修正按统一曲线计算。
- [ ] 高层事件使用软上限和边际收益递减，避免无尽滚雪球。
- [ ] 随机选择使用现有确定性 RNG seam，包含动态权重和连续坏运气保护，保存/恢复后序列连续。
- [ ] 引擎测试覆盖无尽资格、事件池、阶段推进、首领结算、坏运气保护和随机连续性。
