# 05 — 接入事件配置与可解释性 UI

**What to build:** 让玩家在事件卡、配置面板、日志和迁移摘要中看懂事件类别、风险、结算公式和自动处理原因，并能编辑每类自动处理策略。

**Blocked by:** 03 — 实现按类别配置的自动处理; 04 — 增加无尽模式事件池、阶段链与首领事件

**Status:** ready-for-agent

- [ ] 事件卡使用语义化 `data-*` 契约展示主题、类别、风险、选项、成本/产出和阻塞状态。
- [ ] 结算详情可展开显示基础值、阶段/层数倍率、风险倍率、能力修正、软上限和最终值。
- [ ] 自动处理配置支持按类别编辑并显示当前规则、优先级、预算、阈值、冷却和备用策略。
- [ ] 高风险暂停通知明确说明暂停原因和需要玩家处理的事件。
- [ ] 事件历史显示手动/自动来源、命中规则、原因、消耗、产出和风险变化。
- [ ] 旧存档迁移摘要显示换算字段、补偿、未知事件处理和新默认配置。
- [ ] UI 单元测试和 Playwright 测试只使用语义化选择器和行为断言，不依赖样式类名。
