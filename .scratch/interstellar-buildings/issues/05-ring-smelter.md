# 05 — 星环冶炼场（究极·经济向 + 互斥基础设施，垂直切片 #3）

**What to build:** 第一个究极建筑 + 互斥机制核心：**星环冶炼场**（经济向）。解锁前置 = 通关 + 三个星系间建筑各 ≥1 级。全局产出乘数 ×2^level（矿/能源/科技全吃，满级 ×1,024），高耗能 100 能源/s × level（走现有能源消耗结算，能源不足时触发打折惩罚——能源链张力）。同时落地**互斥基础设施**：购买时写入 `megastructureChoice: 'smelter'`，跃迁枢纽（另一方）本周目永久锁定；NG+ 重置字段可重选。UI 新增「终局抉择」独立区块：未选择时两卡片并排展示（效果预览 + 资源需求 + 互斥警告确认弹窗），选定后冶炼场高亮、枢纽显示"本周目已锁定"。NG+ 遗产：重开时按冶炼场等级 ×1.5% 折算永久产出加成（进 `permanentBonuses`）。
