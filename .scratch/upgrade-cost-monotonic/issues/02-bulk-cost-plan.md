# 02 — 统一单次与批量升级成本计划

Type: task
Status: resolved

## What to build

让单次升级、批量预览和批量执行共享逐级成本计划。每一级成本在最终扣除前逐资源向上取整；资源不足时停止在最后一个完整可支付等级。

## Acceptance Criteria

- 预览和执行对相同初始状态生成相同等级序列、逐级成本和总消耗。
- 不使用总成本先算后扣的替代路径。
- 资源不足不会执行部分升级。
- 唯一建筑满级、科技满级和其他现有停止条件保持不变。

## Answer

已实现：预览和执行继续共享 `runLoop` 逐级计划，使用相同的单次成本计算与完整前缀停止语义。
