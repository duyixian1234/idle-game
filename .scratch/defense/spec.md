# Spec: 国防系统与攻占区域

## Problem Statement

游戏后期缺乏主动目标：科技升级满、buy-max 一键买满、外交四派系结盟后，玩家只剩数值膨胀的无限模式。同时存在两个闲置/浅层资产：① 派系 `threat`（威胁度）字段自威慑系统建立以来**只被威慑消耗、从未被任何系统读取**；② 「虫族警报」仅为事件级一次性威胁，无持续存在感。用户希望增加国防系统与需要攻占才能获得的区域，为游戏引入军事维度与主动目标感。

## Solution

新增**统一军事体系**（单一军力资源攻防共用）：军力（第 4 资源 ⚔）由兵营产出、军港提供容量上限（上限截断产出）；派系威胁度 ≥55 时会周期性地军事骚扰殖民地（激活闲置 threat 字段），玩家可花军力击退/付资源买平安/无视；玩家可发起对 4 个第三方区域（虫群前哨/废弃船坞/星际残骸带/虫群母巢）的攻占——投入军力 + 60 分钟倒计时（离线照常推进），成功率 = min(100%, 投入军力/守卫强度)，成功获得一次性奖励 + 永久全局加成 + 个别区域解锁机制（军械科技线）。军事线为中后期支线 + 通关后扩张，不阻塞主线与统一联邦结局；肃清 4/4 区域为完成度指标，不设第二结局。区域永久加成并入 NG+ 永久加成继承池。

## User Stories

1. 作为一名玩家，我希望拥有独立的军力资源（⚔）并建造兵营/军港来产出与扩容，以便有一条与矿/能/科并行的军事养成线。
2. 作为一名玩家，我希望军力达到上限时产出截断，以便形成「攒满→花掉→再攒」的攻占节奏（花在攻占或击退骚扰上）。
3. 作为一名玩家，我希望威胁度高的派系（≥55）会周期性地军事骚扰殖民地，以便国防有真实防御对象（初始铁卫 70/沃克斯 60 会骚扰，天鹅/圣光安全）。
4. 作为一名玩家，我希望骚扰事件可三选一：花军力击退（威胁度 −15）/ 付资源买平安（好感 +5）/ 无视（矿能各 −5%），以便军事流与和平流各有应对通道。
5. 作为一名玩家，我希望结盟的派系永不骚扰，以便结盟从「数值达标」升级为「军事安全」的实质决策。
6. 作为一名玩家，我希望攻占区域时投入军力即可发起，60 分钟倒计时（离线照常推进），回归时结算战报，以便挂机也能推进军事线。
7. 作为一名玩家，我希望攻占成功率随投入军力线性提升、足额投入必成，以便决策感来自投入量而非纯随机。
8. 作为一名玩家，我希望攻占失败只损失本次投入军力且可立即重试，以便失败有代价但不挫伤挂机意愿。
9. 作为一名玩家，我希望防御失败只损失少量可再生资源（矿/能各 5%，离线封顶 30%），建筑/科技/区域/存档永不受损，以便离线挂机永远是净收益。
10. 作为一名玩家，我希望攻占成功获得一次性奖励 + 永久全局加成（军力上限/全产出），个别区域解锁军械科技线，以便区域是长期资产而非一锤子买卖。
11. 作为一名玩家，我希望军事面板显示 4 个区域的守卫强度/奖励预览/攻占状态与肃清进度（x/4），以便有明确的军事完成度目标。
12. 作为一名玩家，我希望攻占虫群母巢后「虫族警报」事件不再触发（叙事闭环），以便世界状态随玩家行动改变。
13. 作为一名玩家，我希望 NG+ 继承区域永久加成（重置军力/建筑/区域攻占状态），以便二周目军事线重打但更强。
14. 作为一名玩家，我希望 buy-max 覆盖兵营/军港（军力达上限时停止购买），以便一键买满不产生纯浪费。

## Implementation Decisions

- **军力资源**：`RESOURCE_KEYS` 扩展第 4 资源 `military`（符号 ⚔，显示「当前/上限」）；产出管线新增军力流，**不吃 planetDrill 等生产科技加成**（独立管线）；军力为**唯一有上限资源**，上限 = 军港数量 × 基数 + 区域永久加成；满上限时兵营产出**截断**（浪费语义，逼消费/扩容）。
- **军事建筑**：两个新全局可堆叠建筑——「兵营」（产军力）+「军港」（军力上限）；轨道工厂站（第 2 星球，矿物 5 万）解锁后出现于第 4 操作面板「军事」；遵循现有建筑升级规则（系数 +0.5×level）与 buy-max 全范围覆盖；**buy-max 停止条件新增「军力已达上限」**（防纯浪费，实现期钉死）。
- **派系骚扰（激活 threat）**：threat ≥ 55 且未结盟的派系，骚扰检查并入现有事件计时器（离线不实时触发，回归时按离线时长结算一次）；骚扰事件卡片三选项：击退（耗军力 = threat×200，threat −15）/ 买平安（耗矿物标定值，好感 +5）/ 无视（矿/能各 −5%）；结盟派系永不骚扰；威慑（-25 threat）成为军事主动解；离线回归自动判定：军力 ≥ 骚扰强度自动击退（扣军力），否则按无视规则扣资源（叠加离线 30% 封顶）。
- **攻占系统**：4 个区域沿主线进度分三段解锁——虫群前哨（冰封星后，低门槛，奖励：一次性 + 解锁军械科技线）/ 废弃船坞（气态巨星后，一次性 + 军力上限 +20%）/ 星际残骸带（母星后，一次性 + 全产出 +10%）/ 虫群母巢（通关后，高门槛，一次性 + 全产出 +25%）；发起 = 锁定投入军力 + 记录 startTime，倒计时 60 分钟（真实时间，离线照常推进）；回归结算：成功率 = min(100%, 投入军力/守卫强度)，失败 = 投入军力全损、可立即重试；守卫强度为区域固定属性，数值实现期模拟定标。
- **区域奖励与永久加成**：区域 = 长期资产（一次性奖励 + 永久全局加成 + 个别机制解锁）；永久加成写入既有 `permanentBonuses` 体系（NG+ 继承），不新增存档语义。
- **军械科技**：新升级线 Lv1-5（攻占虫群前哨后解锁显示），科技点成本，每级 +军力产出系数；与现有 5 项生产科技并列、互不影响。
- **叙事闭环**：保留既有「虫族警报」随机事件；攻占「虫群母巢」后该事件权重归 0（日志仪式感文案）。
- **存档 v3 迁移**：新增 `military` 资源字段、军事建筑计数、`conquest` 区域状态（unlocked/undergoing(含 startTime+投入)/conquered）、区域加成并入 `permanentBonuses`；旧档迁移默认军力 0/建筑 0/区域全部 locked；`threat` 字段已存在无需迁移。
- **UI**：资源条加 ⚔ 军力（当前/上限）；第 4 面板「军事」三段式——① 军事建筑（兵营/军港 + 升级 + buy-max）② 攻占列表（4 区域各一行：守卫强度/奖励预览/攻占按钮/进行中倒计时/已占领标记 + 顶部肃清进度 x/4）③ 军械科技升级；骚扰事件走既有事件卡片体系。

## Testing Decisions

- **seam**：沿用双层 seam——引擎层 Vitest 为主 seam，UI jsdom 冒烟为次 seam；时间相关用注入时钟（既有先例）。
- **引擎层新增覆盖**：军力产出与上限截断（满上限产出停止）；兵营/军港购买与升级（含 buy-max 军力达上限停止条件）；骚扰事件三选项（击退扣军力+threat−15/买平安扣矿+好感+5/无视 −5%）与结盟免疫；离线骚扰结算（自动击退 vs 按无视，30% 封顶叠加）；攻占发起/倒计时推进（注入时钟）/成功率（足额必成、薄投概率）/失败全损可重试；区域奖励与永久加成写入 `permanentBonuses`；母巢攻占后虫族警报权重归 0；存档 v3 迁移（旧档读入军力 0/区域 locked）；NG+（区域加成继承、军力/建筑/区域重置）；回归现有 251+ 测试不破。
- **UI 层覆盖**：资源条军力显示（当前/上限）；军事面板三段渲染（建筑/攻占列表/军械科技）；攻占按钮状态（可发起/进行中倒计时/已占领禁用）；骚扰事件卡片三选项。
- **先例**：`src/engine/*.test.ts` 与 `src/ui/dom.test.ts`；tech-upgrade 的存档迁移测试范式（`researched`→`techLevels`）直接复用为 v2→v3 迁移范式。

## Out of Scope

- 第二结局 / 军事胜利结局（肃清 = 完成度指标，统一联邦保持叙事唯一性）。
- 攻占派系领地（避免污染统一联邦结局与全好感玩法）。
- 军力维护成本 / 负反馈（能源吃军力等）。
- 建筑被毁 / 科技回退 / 区域得而复失等惩罚（挂机铁律：只动可再生资源流）。
- 在线实时战斗 / 派遣式部队状态机（按钮式即时结算 + 自动防御已覆盖）。
- 区域持续产出新资源种类（区域只给一次性 + 永久加成 + 机制）。
- 4 区域以外的扩展区域。
- 军力参与威慑/结盟成本。
