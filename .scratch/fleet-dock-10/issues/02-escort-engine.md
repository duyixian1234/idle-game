# 02 — 护航远征引擎

**What to build:** 引擎层护航远征机制：玩家带舰队发起探索派遣时，可附加「护航」——每次派遣一次性扣除海量能源远征费（单艘 = 能源净产出 × 10s × 舰数），换取探索收获倍率（每艘 +1%）与大额资源返还（返还锚定「基础成本 + 远征费」，能源分支压低、矿物/科技分支突出）。护航要求舰队运转（fleetPowered）；结果在出发时固化，中途停摆不影响。远征费对所有结果分支一视同仁。

**Blocked by:** None — can start immediately（护航在船坞 Lv1-3 即可用，不依赖 01）

**Status:** resolved

- [ ] 单艘远征费 = `netProduction.energy × ESCORT_ENERGY_SECONDS`（10s），总费 = 单艘 × 舰数
- [ ] 护航收获倍率 = `1 + 0.01 × 舰数`，与科技收获倍率乘法叠加，只作用于 resource 分支补偿
- [ ] 护航远征返还锚定（基础成本 + 远征费），能源分支返还压低、矿物/科技突出（常量进 balance.ts）
- [ ] 护航条件 = fleetPowered；停摆时发起护航被拒绝（可发起无护航派遣）
- [ ] 出发时固化：护航费扣减、倍率、返还值全部固化进派遣结果；出发后造船/停摆不影响本笔
- [ ] 远征费对所有结果分支（faction/planet/resource）一视同仁收取
- [ ] 引擎测试：护航费、返还锚定、倍率叠加、停摆拒绝、固化语义、无舰队行为与现状一致
