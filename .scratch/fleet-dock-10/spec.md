# 船坞 10 级 + 舰队护航远征 + 自动探索（fleet-dock-10）

**Status:** ready-for-implementation

## Problem Statement

舰队系统（fleet spec）存在三个成长断点：

1. **船坞 Lv3 封顶**：舰数上限显式表止于 3/6/10，舰队规模没有后续成长空间；且骚扰强度固定（最高 3,500），Lv2 满编（6 艘 = 7,200 战力）已能自动迎击一切——**防御收益在 Lv3 饱和**，升船坞的边际价值趋零。
2. **维护费后期失效**：能源产出指数级膨胀（恒星阵列 2,000/s × 2^level × 冶炼场倍率 × 科技线，极后期每秒数亿），而舰队维护费几何级数封顶（满编 20 艘 ≈ 16.6 万/s = 产出的 0.03%）——**维护费作为「能源取舍」途径在极后期彻底失效**，能源重新溢出。
3. **探索需手动续派**：派遣 60min/轮、3-5 槽并行，玩家需每 60min 回来手动点击续派；离线时只结算在途派遣、不发起新派遣——**挂机体验中断，离线收益受限**。

## Solution

三项机制协同解决：

- **船坞 3→10 级**：舰数上限曲线扩展为 `3/6/10/12/14/16/18/20/22/24`（每级 +2），满编 24 艘维护 ≈ 84 万/s（恒星阵列 Lv11 时代产出的 ~21%，落「生产 vs 军备」取舍带）。骚扰强度固定不缩放——舰队成型 = 骚扰自动退场（减压阀闭环）。
- **舰队护航远征**：探索派遣可勾选「护航」——每次派遣一次性消耗**海量能源**（单艘 = 能源净产出 × 10s × 舰数，锚定产出永不失效），换取收获倍率（每艘 +1%）与**大额返还**（返还锚定基础成本 + 远征费）。舰队 = 一台「溢出能源 → 矿物/科技/收集进度」的转换器，重新激活能源取舍。
- **自动探索**：探索页全局开关 + 护航勾选（默认护航关），自动用全部空槽循环派遣；**离线同样自动续派**（每 60min 结算 → 续派循环，资源耗尽自然停）。

存档升 **schema v10**（新增 `autoExplore: { enabled, escort }`）。

## User Stories

1. 作为舰队玩家，我希望船坞能从 3 级升到 10 级，以便舰队规模有持续的成长空间。
2. 作为舰队玩家，我希望船坞每升一级舰队上限 +2（Lv10 = 24 艘），以便升级回报可预期、曲线线性可读。
3. 作为舰队玩家，我希望骚扰强度不随舰队成长而升级，以便舰队成型后能真正获得安宁（减压阀闭环）。
4. 作为中期玩家，我希望探索派遣时可以选择「护航」，以便用一次性能源投入换取探索收益提升。
5. 作为后期玩家，我希望护航远征费锚定当期能源产出（单艘 = 净产出 × 10s），以便能源产出膨胀时这笔开销依然「疼」、能源取舍永不失效。
6. 作为后期玩家，我希望护航远征的返还锚定远征费而非基础成本，以便「海量投入」有「海量回报」与之匹配。
7. 作为玩家，我希望每艘护航舰提供 +1% 探索收获倍率，以便舰队规模与探索收益同向成长。
8. 作为玩家，我希望护航舰数 = 当前舰数（加成与费用同一杠杆），以便「值不值」的权衡始终一致。
9. 作为玩家，我希望舰队停摆（能源不足）时不能发起新的护航远征，以便停摆语义一致（无战力即无护航）。
10. 作为玩家，我希望已出发的护航远征结果在出发时固化，以便中途停摆不影响结果、防 SL 契约结构上成立。
11. 作为玩家，我希望无舰队时探索行为与现状完全一致（不付费不加成），以便护航是纯增量、不破坏既有体验。
12. 作为玩家，我希望探索页能看到护航费用与加成预览，以便出发前清楚知道这笔交易的代价与回报。
13. 作为玩家，我希望探索页有「自动探索」开关，以便不再每 60min 手动续派。
14. 作为玩家，我希望自动探索默认不带护航（需手动勾选），以便离线时不会被护航费抽干能源。
15. 作为玩家，我希望离线时自动探索照常续派（每 60min 结算 → 续派），以便离线挂机也有完整探索收益。
16. 作为玩家，我希望自动探索无额外轮次上限、资源耗尽自然停，以便行为可预期（与手动一致）。
17. 作为玩家，我希望自动探索资源不足时自动暂停、资源恢复后自动继续，以便零操作负担。
18. 作为玩家，我希望自动派遣同样计入探索统计与成就口径，以便自动/手动行为一致。
19. 作为玩家，我希望新增「编队护航」与「星海霸主」成就，以便舰队长线目标有仪式感。
20. 作为玩家，我希望旧存档（v9 及更早）自动迁移出 autoExplore 字段（默认关闭），以便更新不丢进度。

## Implementation Decisions

### 船坞 10 级

- `BuildingDef` 船坞（dock）`maxLevel: 3 → 10`；`DOCK_SHIP_CAP` 扩展为 10 级显式表 `{1:3, 2:6, 3:10, 4:12, 5:14, 6:16, 7:18, 8:20, 9:22, 10:24}`（每级 +2，非等差但线性）。船坞 0 级仍 = 无舰队。
- 船坞描述文案不再硬编码 Lv1-3 字样，改为按等级动态展示或泛化表述（避免 10 级下文案失真）。
- 升级成本维持 unique 公式 `baseCost × 2^level`（2000 万矿 × 2^level；Lv10 总投入 ≈ 102 亿矿，终局期可负担）。bulk 买满/升满对 unique 大件维持禁用。
- 骚扰强度（`RAID_STRENGTH_MULT` 与 threat 上限）**不动**。

### 护航远征（引擎纯函数，集中在舰队/探索模块）

- 新派生函数（零存档）：
  - 单艘远征费 = `netProduction.energy × ESCORT_ENERGY_SECONDS`（常量初始 10s）；总远征费 = 单艘 × 当前舰数。
  - 护航收获倍率 = `1 + FLEET_HARVEST_PCT_PER_SHIP × 舰数`（常量初始 0.01）。
  - 护航条件 = `fleetPowered(state)`（有舰且能源 ≥ 总维护费）。
- `startExpedition` 增加护航参数：护航 = true 且 fleetPowered → 额外扣远征费（能源，派遣时一次结清）；返还计算改为**锚定（基础成本 + 远征费）**：resource 分支补偿 = (基础矿物/能源成本 + 远征费) × 返还率 × (科技收获倍率 × 护航倍率)，派遣时固化进结果（不存档护航标记）。
- 远征费对所有结果分支（faction/planet/resource）一视同仁收取；护航倍率只作用于 resource 分支补偿（与科技倍率同语义，不碰 60min 时长锚点、不作用于天体产出）。
- 护航专属返还率：energy 分支压低（投入能源却返还能源无意义），突出 mineral/tech 分支——具体值 balance-sim 定标。
- NG+：舰队随周目归零 → 护航自然失效；远征费无跨周目残留。

### 自动探索

- 存档 schema **v10**：新增 `autoExplore: { enabled: boolean; escort: boolean }`（默认 `{ enabled: false, escort: false }`）。迁移链追加 v9→v10，schemaVersion 写死 SCHEMA_V10（沿用 fixed-rng 起防跳级惯例）；缺省补默认值、幂等。
- **在线**：tick 内探索结算后，若 `autoExplore.enabled` 且存在空槽 → 自动发起派遣（逐槽，等价机器代按手动）；`autoExplore.escort` 决定该自动派遣是否带护航。
- **离线**：离线结算模拟「每 60min 结算 → 自动续派」循环（按封顶时长推进，3-5 槽 × 8-12 轮）；派遣走同一 startExpedition 路径（含护航费扣减、rng 走 explore 域持久化计数器、结果固化）——**防 SL 契约不破**。
- **资源不足**：某次自动派遣失败（矿物/能源/军事点/护航费不足）→ 跳过该轮并暂停自动探索（enabled 保持开），下个 tick/离线结算资源恢复后自动继续；日志提示「资源不足，自动探索暂停」。
- **无额外轮次上限**：自动探索跑到资源耗尽或开关关闭为止（在线/离线行为一致）。
- 自动派遣计入 `stats.explorations`（成就口径与手动一致）。
- 命名区分：探索页用「自动探索」，与事件自动处理（automationPolicies）语义隔离。

### UI

- 探索页：自动探索开关 + 护航勾选（`data-auto-explore` 系列），明示「自动护航预计消耗 X 能源/轮」；手动派遣的护航勾选（`data-escort-*`）+ 费用/加成预览；舰队停摆时护航选项禁用并提示「舰队能源不足」。
- 星域页舰队分组：显示护航加成说明（每艘 +1%、当前倍率）。
- 船坞卡：升级按钮按 maxLevel 10 渲染。

### 成就

- `escortFirst`「编队护航」：首次带舰队完成护航远征（collect 类）。
- `dockLord`「星海霸主」：船坞升至 Lv10（collect 类）。成就命名与护航日志文案实现期定稿（同源谓词防数值漂移，参照 endlessii 先例）。

## Testing Decisions

- **主 seam（引擎纯 TS）**：沿用 `fleet.test.ts` / `exploration.test.ts` / `save.test.ts` / `offline.test.ts` 先例。覆盖：
  - 船坞解锁链与 maxLevel 10 封顶、`DOCK_SHIP_CAP` 10 级曲线（含旧档 Lv3 行为不变）；
  - 护航费（锚定净产出 × 10s × 舰数）、护航倍率（+1%/艘）、返还锚定（基础成本+远征费）、科技×护航倍率乘法叠加、只作用 resource 分支；
  - 护航条件（fleetPowered；停摆拒绝）；结果固化（出发后造船/停摆不影响本笔）；
  - 自动探索：开关续派、护航偏好生效、资源不足暂停/恢复、离线循环续派（封顶时长内轮次与资源扣减）、无额外上限；
  - 迁移 v9→v10：写死 SCHEMA_V10、缺省补 `{enabled:false,escort:false}`、幂等；旧档加载 autoExplore 默认关。
- **次 seam（dom 冒烟）**：探索页自动探索开关/护航勾选/预览/停摆禁用渲染；船坞卡 10 级升级渲染，沿用 `dom.test.ts` 先例。
- **E2E（用户手动执行，agent 不跑）**：v9→v10 迁移、船坞满级（升级到 Lv10 舰数上限 24）、护航远征全流程（费用扣减/加成/返还/停摆禁用）、自动探索在线续派与离线续派（离线 8h 后轮次与资源断言）；复用 seedSave + lockSaveStore 注入技巧与「playing 档派系未统一」铁律。
- **balance-sim（一次性，跑完即删）**：护航性价比（溢出能源换矿物/科技是否值得）、能源→矿物转换率防「无限能源→无限矿物」、离线自动探索收益冲击（8h ≈ 8 轮/槽 vs 现状 1 轮）、24 艘满编维护 ≤ 当期产出 30%、收集节奏。若护航收益不足以驱动玩家，上调倍率/下调费率。
- 好测试的标准：只断言外部行为（资源扣减、日志文本、事件是否出现），不断言内部实现细节（派生字段名等）。

## Out of Scope

- 舰船升级系统（每艘可独立升级战力/维护）、新舰型（驱逐舰/巡洋舰）——各自独立 feature。
- 骚扰强度随周目/舰队缩放——已否决（减压阀闭环）。
- 探索时长锚点（60min）改动——护航/自动探索均不碰。
- 探索天体产出受护航倍率影响——不作用。
- 探索自动处理的模板配置（目标类型优先级等）——奖池随机轮盘，目标优先级无实义。
- 事件自动处理（automationPolicies）——独立系统，仅命名区分。
- 能源产出的削减——本期只加消耗途径。

## Further Notes

- 数值锚点（balance-sim 校准定稿，防回归断言入引擎测试）：
  - `ESCORT_ENERGY_SECONDS = 10`（单艘远征费 = 净产出 × 10s）；`FLEET_HARVEST_PCT_PER_SHIP = 0.01`（每艘 +1%，满编 +24%）。
  - **极后期防印钞锚定（实现期定稿，2026-08-07）**：mineral 分支按「远征费的当期矿物等价」折算（`mineralFee = fee × 矿物产出/能源产出`）——mineral 时间等价恒 = 返还率 × 倍率（实测 240s 能源 → 267.8s 矿物，时间等价 1.12 = 0.75 × 1.49），与场景无关（能源产出 >> 矿物产出时不会出现 240s 能源 → 数十万秒矿物的结构性印钞）；energy 分支锚定远征费本身（0.2，投入能源返能源无意义）；tech 分支锚定远征费量级（0.02，sim 验证满负荷 0.41× 科技产线/小时，大额但不印钞）。
  - 护航经济模型：返还锚定（基础成本 + 远征费折算）× 返还率 × 倍率——亿级投入 → 亿级产出，数量级匹配。
  - 24 艘满编维护 84 万/s ≈ 恒星阵列 Lv11（400 万/s）时代产出 21%，落 15-30% 取舍带（极后期趋 0 为已知现象——护航费补位能源取舍）。
  - 离线自动探索 8h（枢纽 12h）/60min = 8-12 轮/槽，收益冲击 sim 校准。
  - **sim 实测（2026-08-07，后期档恒星 Lv10+冶炼 Lv2=409.6 万/s、dock Lv10 满编 24 艘、3 槽，autoExplore 开）**：
    - 维护/产出 20.6% ≤ 30% 硬约束通过；单艘护航费 4,096 万、总 9.83 亿/轮。
    - 护航 resource 分支返还：矿 18.3 亿 / 科技 4,877 万 / 能 4.88 亿（矿返还/能源投入 ≈ 1.86、科技 ≈ 0.05）；非护航矿返还 22.5 万——护航驱动 ≈ 823×，收益足以驱动玩家，常量零调整。
    - 能源→矿物无循环漏洞：矿物不可直接兑换能源；返还比率锚定（0.75×倍率），上限受舰队规模与净产出约束。
    - 离线 8h = 8 轮/槽：24 次派遣 + 24 结算日志（每轮双日志），vs 现状 1 轮——收益冲击 ~8×，资源耗尽自然停、暂停冷却正常。
    - 收集节奏：护航不改变奖池（4 faction×2 + 5 planet×1 + resource×6）、faction/planet 分支无补偿。
    - **极后期复校（NG+2 + 冶炼 Lv10 + 恒星 Lv11，能源 882 亿/s、矿物 3.35 亿/s、科技 2.1 亿/s）**：单艘护航费 8,820 亿、总 2.1 万亿；一次护航投入 240s 能源产出 → 换回矿物 267.8s 产出（时间等价恒 1.12，防印钞折算生效）+ 科技 625 亿（0.41× 科技产线/小时）+ 能源回收 30%；每小时全槽护航矿物流入 0.22× 矿物产线（3 槽）——**防「无限矿物」为结构性机制（时间等价恒 ≤3×，船坞封顶后不随能源膨胀漂移）**；维护费占比极后期趋 0.001%（护航费补位能源取舍，spec 已知现象）。
  - **E2E 手动执行说明**：护航费用/返还断言用相对口径（出发无「资源不足」日志 + 返航日志含护航标注），不断言绝对值——防常量微调后 E2E 失效。
- 存档 v10 版本号协调：bug-defense 已实现占用 v10（migrateV9ToV10 在 main），本 feature 顺延用 **v11**（SCHEMA_V11 = 11）——已定稿，见 save.ts 迁移链。
- 自动探索 rng：离线自动派遣走 explore 域持久化计数器（与手动同域），seed 固定可复现，防 SL 结构不破。
- 舰队维护费/软降级/骚扰自动迎击逻辑**零改动**——护航远征是叠加的第二个能源出口（停泊维护费 + 任务远征费）。
