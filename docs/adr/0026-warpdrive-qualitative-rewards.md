# 星舰推进（warpDrive）满级质变：动收益不动成本

warpDrive 星舰科技线（通关后解锁，Lv20，成本 `base × 1.7^lv` 累计 ≈ 11.6 亿科技点）在末 5 级（Lv16→20）吃掉累计投入的 ~88%，而每级奖励仅 +10% 舰队战力——「荣誉升级」的体验落差。决策：**成本曲线保持 1.7^lv 不动，在 Lv10 / Lv20 各挂一个摩擦降低型质变**——Lv10 = 探索派遣军力消耗 −10%；Lv20 = 护航远征费 −10%。

**状态**: Accepted（2026-08-08 定稿，grill 三轮 Q2/Q4）
**证据**: `src/engine/data.ts:459`（warpDrive）；`src/engine/exploration.ts:103/159`（expeditionMilitaryCost / escortFee）；`src/engine/balance.ts:40`（TECH_UPGRADE_GROWTH）；ADR-0025（科技点出口演进）

## 背景

warpDrive 累计成本 11.6 亿科技点（Lv20 单级 ≈ 4.78 亿），末 5 级 ≈ 10.2 亿（88%）。这是 ADR-0025 科技点出口锚定的结构保证——1.7 指数让科技点「永远不够花」。但满级与 Lv16 体验无差（都是线性 +10% 战力），玩家对「11.6 亿投入」缺乏终点感。候选修复有三：动成本（软上限改多项式）、动收益（挂质变）、维持纯荣誉。

## 决策

1. **动收益不动成本**：成本曲线 `1.7^lv` 原样保留（ADR-0025 出口容量 11.6 亿是 balance-sim 断言，不可动）。
2. **Lv10 质变 = 探索派遣军力消耗 −10%**：`expeditionMilitaryCost` 在 `warpDrive ≥ 10` 时 ×(1 − 0.1)。军力是容量资源、消耗后需兵营补充——减消耗 = 更多探索轮次，不产生新产出源、不印钞。
3. **Lv20 质变 = 护航远征费 −10%**：`escortFee` 在 `warpDrive ≥ 20` 时 ×(1 − 0.1)。护航费锚定 10 秒能源净产出（ADR-0024），减费 = 溢出能源转换效率 +11.1%，仍锚定产出不脱钩。
4. **排除的候选**：护航收获倍率与离线封顶已被跃迁枢纽占用（JUMPGATE_HARVEST_MULT / JUMPGATE_OFFLINE_EXTRA_SECONDS），不做二次叠加；软上限改多项式直接摧毁 11.6 亿出口容量断言（否决）。
5. **新常量入 balance.ts 根因子区**：`WARP_EXPEDITION_COST_REDUCTION = 0.1`、`WARP_ESCORT_FEE_REDUCTION = 0.1`（或合并同值常量），不散落 magic number。

## 为什么

- 两个质变都是「摩擦降低」型：减军力消耗/减能源费，不改变收益倍率、不增加产出上限——经济结构零扰动，只是让满级舰队「用起来更顺」，与 +10% 战力/级的既有杠杆同向（舰队越强，派遣与护航越便宜）。
- 质变挂在 Lv10/Lv20 而非逐级：与成就 warpVeteran(Lv10)/warpMaster(Lv20) 对齐，每 10 级一个「可感知的台阶」，避免 20 级逐级加成的数值噪声。
- 收益侧改动可逆（改回 1.0 即还原），成本侧改动不可逆（破坏出口断言）——「动收益」是低风险一侧。

## 后果

- `exploration.ts` 两处函数需读 `techLevels.warpDrive`（探索质变与护航质变独立判定）。
- balance-sim 补断言：Lv10 派遣军力 = 0.9×原值；Lv20 护航费 = 0.9×原值（锚定产出不脱钩仍成立）。
- 科技卡 desc/effect label 更新：「Lv10 派遣军力 −10% / Lv20 护航费 −10%」。
