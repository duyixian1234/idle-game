# PWA 可安装外壳：manifest + Service Worker 离线缓存

ADR-0050：游戏为纯前端单页应用（Cloudflare Pages 静态托管，push main 自动构建）。此前为普通网页形态：依赖网络加载、无安装能力、无离线兜底。本 ADR 接入 PWA 核心三件套（Web App Manifest + Service Worker 预缓存 + 图标），使游戏**可安装（主屏/桌面）+ 断网仍可完整加载游玩**，不触碰引擎/存档/离线收益逻辑。

**状态**: Accepted（2026-08-11，grill 10 决策见 `docs/grill-log-pwa.md`；spec 落 `.scratch/pwa/spec.md`）
**证据**: `vite.config.ts`（VitePWA 插件，`registerType: 'autoUpdate'` + workbox generateSW）；`src/pwa-manifest.ts`（manifest 单一真源）；`src/pwa.ts`（注册模块）；`src/pwa.test.ts` / `src/pwa-manifest.test.ts`（容错与配置断言）；`scripts/gen-pwa-icons.mjs` + `scripts/pwa-icon.svg`（图标生成）；`public/pwa-192.png` / `pwa-512.png` / `pwa-maskable-512.png` / `apple-touch-icon.png`；`index.html`（iOS meta）；`scripts/check-pwa-build.mjs` + `.github/workflows/ci.yml`（构建产物断言）

## 背景

游戏部署于 Cloudflare Pages（根路径，主域有边缘缓存延迟）。玩家场景以移动端长驻挂机为主（关闭页面后引擎按存档时间差结算离线收益，8h 封顶）。两个事实约束方案：

1. **无后端**：无服务器推送通道 → 推送通知/Background Sync/Periodic Sync 无落点，出范围。
2. **离线收益已内建**：IndexedDB 自动存档（5s 节流）+ 引擎离线结算——「离线挂机」语义已由引擎承担；SW 只负责**应用外壳**（HTML/CSS/JS/字体/图标）的离线可加载，两者正交互补。

## 决策

1. **实现方式**：`vite-plugin-pwa@^1.3.0`（`mode: 'generateSW'`，workbox）——构建期生成 `sw.js` + `manifest.webmanifest` 并注入注册；pre-cache 清单按产物内容 hash 自动生成，无需手写维护。peer 支持 Vite ^8.0.0（已核验）。
2. **缓存策略**：HTML `network-first`（`navigateFallback: 'index.html'` 兜底，保证新版生效）；hashed 静态资源 `CacheFirst`（hash 即不可变，workbox 对 build 产物的默认行为）；无第三方请求（JetBrains Mono 已自托管，ADR 无关前置定案）→ 不配 `runtimeCaching`。
3. **更新策略**：`registerType: 'autoUpdate'`（workbox `skipWaiting + clientsClaim`）——新 SW 立即接管，**不自动 reload 页面**（250ms tick 在内存、挂机长驻，打断不可接受；IndexedDB 5s 保存，刷新丢 ≤5s 进度，用户自然刷新即用新版）。
4. **图标**：手写 SVG 源（`scripts/pwa-icon.svg`，终端风：`#050505` 底 + 磷光绿 `#33ff00` 星环钻头，与 `--phosphor` 主题一致；符号主体落中心 80% 直径安全区内 → 同图可作 maskable）→ sharp 一次性生成 PNG（192/512/maskable-512/apple-touch-icon-180）提交入库，CI 不依赖生成。
5. **manifest**（`src/pwa-manifest.ts` 单一真源）：`name=深空拓荒 · 星系统一联邦`、`short_name=深空拓荒`、`theme_color=background_color=#050505`、`display=standalone`、`lang=zh-CN`、`start_url=scope=./`（与 `base: './'` 一致）。
6. **注册容错铁律**（`src/pwa.ts`）：`navigator.serviceWorker` 缺失（非安全上下文/private 模式）或 `register()` reject → console.warn 后静默返回，**绝不阻断游戏启动**；模块级幂等 guard；`void registerPwa()` 不 await 首帧。
7. **测试**：vitest 断言注册容错/幂等 + manifest 配置漂移（图标覆盖/maskable/主题色）；`scripts/check-pwa-build.mjs` 在 CI build 后断言 `dist/sw.js`、manifest 可解析、图标文件真实存在。不测 workbox 内部，不引入 E2E（ADR-0019）。

## 为什么

- **generateSW 而非手写 SW**：产物 hash 化后 pre-cache 清单必须构建期生成，手写需自维护清单（易漂移）；vite-plugin-pwa 为 Vite 生态标准，构建期零运行时成本。
- **network-first HTML + CacheFirst assets**：HTML 是版本更新的唯一载体（无 hash），必须网络优先；静态资源 hash 化后缓存永不失效，CacheFirst 最优。
- **autoUpdate 不自动 reload**：挂机游戏会话价值 > 即时更新；skipWaiting 保证下次打开即新版，无需手动清缓存。
- **i18n 零改动**：范围控制（不做设置页离线指示 UI，grill Q9 出范围），新增 UI 文本为零——规避 ADR-0045 的 zh/en 对称 key 化成本。
- **注册容错为铁律**：SW 是增强而非必需；任何环境下游戏必须可玩。

## 后果

- **能力**：可安装（Chrome/Edge/Safari 主屏）、断网完整游玩、版本自动更新、启动屏（standalone + theme_color）。
- **构建产物**：`dist/` 新增 `sw.js` + `manifest.webmanifest` + 4 枚 PNG（共约数十 KB，可忽略）；workbox 预缓存清单随内容 hash 自动失效。
- **引擎/存档**：零改动（SCHEMA 不变）；离线收益语义不变（SW 管外壳、引擎管收益，边界清晰）。
- **测试**：`pwa.test.ts` 5 例 + `pwa-manifest.test.ts` 3 例；全量 vitest 全绿 + `tsc --noEmit` 零错误；CI 增加产物断言步骤。
- **部署**：Cloudflare Pages 静态托管对 SW 天然兼容；主域边缘缓存对 `sw.js` 的更新延迟由 network-first 缓解（首次 offline 后仍以缓存兜底）。
- **关联**：↔ ADR-0001（引擎零 DOM——SW 注册在 UI 层 `main.ts`，引擎无感知）；↔ ADR-0019（无 E2E，构建产物断言 + 用户手动验证安装）；↔ ADR-0045（i18n——v1 无新增文本，后续设置页指示须 key 化）。
