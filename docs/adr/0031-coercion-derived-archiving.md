# 胁迫态派生折叠：subjugated/treaty 中 → 折叠区，状态变化自动折/展

折叠判定原为 `archivedRounds[id] != null || f.allied`（`panels.ts:535`），只覆盖结盟（`diplomacy.ts:229`）与攻占成功（`conquest.ts:150`）两个写档入口；臣服、条约中的派系停留在主列表。决策：**折叠判定扩展为派生条件——`subjugated || treaty 进行中` 的派系移入折叠区；状态变化（条约到期/叛变/赎罪）自动折/展，不写存档**；折叠区保留胁迫管理入口（赎罪/续签）。

**状态**: Accepted（2026-08-08 定稿，grill Q21）
**证据**: `src/ui/panels.ts:533-536`（折叠判定现状）；`src/ui/fold-archived.test.ts`（折叠语义测试）；`src/engine/diplomacy.ts:396-412`（coercionTick：条约到期/叛变流转）、`467-486`（factionAtone）

## 背景

1. **胁迫态留在主列表**：臣服（锁 25% 军力 + 双倍贡税）、条约（12h 税流）中的派系不可再交互（除赎罪/续签），却占用主列表——UI 不整洁。
2. **胁迫是临时态**：条约 12h 到期 threat 反弹、臣服在军力跌破锁定量时叛变、赎罪解除——与结盟/攻占的「永久终态」不同。若写 `archivedRounds` 永久折叠，临时态被当永久态处理，到期后无法自然回流主列表。
3. **折叠区当前无交互**：`archive-row` 只渲染名称/徽章。若臣服/条约派系被折叠而折叠区不可交互，**赎罪路径会被 UI 锁死**（赎罪是玩家主动退出胁迫的唯一通道）。

## 决策

1. **派生判定**：折叠条件扩展为 `archivedRounds[id] != null || f.allied || f.subjugated || (f.treatyUntil !== undefined && nowMs < f.treatyUntil)`——纯派生，不写存档、零迁移。
2. **状态驱动折/展**：条约到期 / 臣服叛变 / 赎罪解除 → 派生条件变假 → 自动移回主列表（渲染全量重建天然成立，受 ADR-0014 约束）。
3. **折叠区保留胁迫管理入口**：对 `subjugated` / 条约中的折叠条目保留「赎罪」「续签」按钮，防止赎罪路径被折叠锁死；结盟/攻占条目不渲染交互（现状不变）。
4. 折叠条目徽章区分状态：`已臣服` / `条约中`（区别于结盟的 `已结盟`、攻占的 `已肃清`）。

## 为什么

- 派生判定而非写档：胁迫状态是生命周期（进入→存续→退出），状态驱动折叠/展开与 `coercionTick` 的状态流转天然对齐，无存档同步问题。
- 赎罪入口保留：若折叠 = 不可交互，则臣服/条约派系永远无法赎罪（折叠即锁死）——违背「三重赎罪」设计（ADR-0011 的退出通道必须可达）。
- 与 ADR-0030 自动胁迫联动：胁迫线派系走「勒索→条约→折叠」，友好线派系走「贸易→结盟→折叠」，两条线都收敛到折叠区，生命周期自动闭环。

## 后果

- **`panels.ts` 折叠判定 + 折叠区渲染扩展**：需区分交互型折叠（胁迫）与非交互折叠（结盟/攻占）；`fold-archived.test.ts` 补胁迫态用例（条约中折叠、到期自动展开、叛变展开、赎罪按钮可达）。
- **依赖 `nowMs` 的派生**：折叠判定需实时时间（条约 `treatyUntil` 对比）——渲染层已持有 `nowMs`，无新依赖。
- 折叠区从「纯只读展示」变为「部分可交互」：UI 结构从 `archive-row` 扩展为带 action 的条目，DOM 契约需同步（ADR-0020 语义化 data-* 断言）。
