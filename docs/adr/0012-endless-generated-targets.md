# 无尽模式生成目标：程序生成零永久加成（防无限叠加摧毁 balance）

无限模式的军事/外交/天体目标分两源：**手写保底**（batch 1/2，可带 `bonus` 永久加成）与**程序生成**（batch 0，仅一次性资源奖励，**永不发 permanentBonus**）。生成后定义快照随档落盘（防 RNG 漂移），NG+ 清空重注入；归档 = 本周目语义。

**状态**: Accepted
**日期**: 2026-08-07（v12 存档，endless-expansion）
**证据**: `src/engine/types.ts:228-263`（GeneratedTarget 注释）；`src/engine/balance.ts:243-268`（生成参数族）；commit `b9f2e96`（无尽探索扩充）

## 背景

无限模式（通关后）需要源源不断的新目标维持挂机内容，但**程序生成是无限供给**——若生成目标带永久加成，玩家可无限刷目标叠永久收益，数值必然爆炸（印钞机）。手写保底是有限内容，永久加成可控。

## 决策

1. **两源分治**：手写保底批次（batch 1 进入无尽解锁、batch 2 第 15 次探索解锁）可带 `bonus: { kind: 'production' | 'militaryCap', value }`；程序生成（batch 0）的军事目标奖励**仅一次性矿物/科技**，`bonus` 字段类型上不可存在。
2. **定义快照落盘**：`generatedTargets: GeneratedTarget[]` 随档保存，生成后固定（`endless:<defId>` 手写 / `gen:<kind>:<n>` 程序）；`archivedRounds` 记录归档周目（本周目语义，NG+ 清空重注入）。
3. **强度周目缩放**：程序生成守卫 `guard × GEN_STRENGTH_GROWTH^ngPlusLevel`（1.5/周目，与探索成本同构），奖励 = guard × 区间因子——比例锚定静态目标量级（5 万矿/500 守卫），封死不破现有天花板。
4. **数量上限**：目标上限 = 探索完成次数 / 10 + 1，随探索节奏逐步放量，不一次性灌满。

## 为什么

- 程序生成无限供给 + 永久加成 = 数值必炸；**一次性资源奖励**把生成目标锁进「消耗循环」（资源 → 目标 → 一次性回报 → 资源），不产生永久存量。
- 快照落盘继承「结果出发时固化」（ADR-0008）的防漂移原则：生成随机序列与生成结果解耦，加载存档不会重生成。
- 周目缩放与探索成本同构，保证高周目生成目标仍有摩擦、不塌缩（同 ADR-0022 的相对价格思路）。

## 后果

- 程序生成派系结盟后进 `factionCodex`，NG+ 清空 generatedTargets 后其 id 仅作历史记录（ngplus.ts 注释明确）。
- 新生成目标类型必须遵循「一次性奖励」铁律——任何给生成目标加永久加成的改动都违反本 ADR，需先通过 balance 论证。
- `GEN_*` 参数族（守卫区间/奖励因子/好感威胁区间/天体产出区间）全部集中在 balance.ts，标注 sim 校准。
