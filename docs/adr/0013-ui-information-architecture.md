# UI 信息架构：4 一级 tab（星域/档案/探索/设置）+ 固定 header/footer

主界面重构为 4 个一级导航 tab：**星域**（机制条 + 日志区 + 二级 tab 建造/科技/外交/军事）/ **档案**（声望 + 成就图鉴 + 统计）/ **探索**（通关前锁定占位页，通关后派遣面板内嵌页 + NG+ 终局卡）/ **设置**（音频/日志/存档管理/危险区/关于）。header 固定两行（资源条 + 星球条），footer 固定纯导航（44px icon+label），单套响应式适配移动端。

**状态**: Accepted
**日期**: 2026-08-06（ui-restructure 定稿，grill 五轮 19 决策）
**证据**: `.scratch/ui-restructure/spec.md`；`src/ui/session/index.ts:150-164`（一级页渲染）；commit `3685c03`（日志并入二级 tab）、`df76aaf`（移动端紧凑）

## 背景

四项真实痛点：① 单页纵向滚动 + 底部 5 tab 平铺，无 header/footer 语义结构，7 个系统工具按钮（静音/排序/导出/导入/探索/NG+/重置）与玩法操作混在一起；② 事件/成就无主动通知（角标/红点），玩家在深处 tab 或离线时错过抉择；③ 无独立设置入口；④ 探索入口通关前完全不显示，玩家无法预知终局玩法。

## 决策

1. **一级 tab = 玩法与系统的分类**：星域（玩法主体）/ 档案（收藏）/ 探索（终局玩法）/ 设置（系统操作分组），`data-nav` 契约。
2. **探索内嵌页**：一级 tab 常驻可点（移动端无 hover，不做置灰）；通关前显示锁定占位（🔒 + 解锁条件 + 玩法预览），通关后渲染派遣面板（`.explore-overlay` 退役为页面渲染）；NG+ 操作卡放探索页顶部。
3. **设置分组**：音频 / 日志 / 存档管理（导出导入）/ 危险区（重置红字）/ 关于；toolbar 与 status-line 废弃。
4. **契约稳定**：既有 `data-resource/data-planet/data-tab/data-event/data-ngplus/data-tool` 等契约原样保留，新增 `data-nav/data-nav-page/data-log`——E2E 断言语义化迁移（ADR-0020）。
5. **footer/header 不参与 250ms 重建**：layout 一次性构建，tick 只重建面板内容（规避 hover 动画闪烁/transition 重放坑）。

## 为什么

- 信息架构按「玩法 vs 系统」分层，7 个平铺按钮的混乱被设置页分组吸收；探索常驻 tab 把「通关后内容」变成可预知的推进目标。
- 单套响应式（Q9）而非两套布局：移动端约束优先，桌面端仅居中 max-width——避免双套 DOM 维护。
- 契约稳定 + 不重建骨架 = 250ms 全量重建约束下（ADR-0014）布局风险可控、可回滚。

## 后果

- 二级 tab 记忆（日志/建造/…上次选择）以 localStorage 持久化（白名单校验，脏值回退）——UI 偏好不进存档。
- 一级导航角标（事件/成就/日志差值，读即已读）是纯 UI 派生，零引擎/存档变更（ADR-0014）。
- 后续新增「页面级功能」（如生产分解面板、自动配置面板）都挂在既有 tab 体系下，不再扩散新入口。
