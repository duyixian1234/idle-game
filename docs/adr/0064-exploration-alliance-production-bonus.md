# 探索结盟提供跨周目资源产出加成

探索外交在当前周目进入可探索阶段后提供 1.05 倍资源产出；每个已结盟派系首次成功结盟再增加 0.05 倍。该累计加成跨 NG+ 保留，但具体派系关系与探索状态仍按既有规则重置，避免继承可交互关系同时保留长期外交投资回报。

**状态**: Accepted（2026-08-15，用户确认；v19 修订计数池与封顶）

## 决策

1. **独立于既有口径**：探索外交加成新增固定 0.05 基础项与探索结盟累计项；ADR-0048 的有名派系结盟计数与范围不改。
2. **计数（v19 修订）**：计数池 = **全部已结盟派系**（静态 4 家 + 探索势力 4 家 + 程序生成派系 gen:/endless:），由 `factionAlliance` 统一入册；同一势力不重复计数，关系失效不回收。v18 初版仅统计 EXPLORE_FACTIONS 四家，v19 起扩大至全部结盟目标（含程序生成派系）。
3. **倍率与封顶（v19 修订）**：当前周目未进入 `ended/infinite` 时探索外交贡献为 1.00；进入后为 `1.05 + 0.05 × 结盟累计次数`，**封顶 +400%（×5.0）**——程序生成派系无限供给，若不设上限数值必然爆炸（ADR-0012 修订：程序生成派系结盟计入，但整体加成设 cap 兜底）。该贡献与既有有名派系加成采用加法合并。
4. **资源边界**：覆盖所有资源产出，包括离线收益与资源型掉落；不放大兑换结果、消费返还或非资源奖励。
5. **生命周期**：累计次数跨 NG+ 保留，具体派系关系、探索进度及其他周目内外交状态继续按既有 NG+ 规则清空。

## 为什么

探索外交的长期价值需要在发现与结盟后持续体现，但不应改变既有有名派系加成口径，也不应让新周目前期绕过探索阶段获得终局收益。只保存累计投资而不保存关系状态，在保留长期成长的同时避免继承可交互外交状态。

v19 修订（2026-08-15）：初版仅将 4 家探索势力计入，与玩家"已结盟 95 个目标"的体感严重脱节——绝大多数结盟目标是程序生成派系，但零加成（ADR-0012 红线）。修订后全部结盟派系入册，同时设 +400% 封顶（约 79 个结盟目标触顶），在保留结盟成长反馈的同时防止程序生成派系无限叠加摧毁数值。

## 后果

- 产出倍率需要区分当前周目探索阶段开关与跨周目累计次数。
- NG+ 存档迁移必须保留累计次数，并对旧档提供无累计次数的默认值。
- 既有 ADR-0048 的矿/能源/科技范围保持不变；新增探索外交贡献按"所有资源产出"口径处理。
- v18→v19 迁移：将当前已结盟的全部派系 id 并入 `explorationAlliances`（去重），旧档升级后立即按新计数池生效。
- ADR-0012"程序生成零永久加成"红线被修订：生成派系结盟计入探索外交计数，但整体加成有 cap 兜底；其余一次性奖励语义不变。
