# 探索结盟提供跨周目资源产出加成

探索外交在当前周目进入可探索阶段后提供 1.05 倍资源产出；每个探索势力首次成功结盟再增加 0.05 倍。该累计加成跨 NG+ 保留，但具体派系关系与探索状态仍按既有规则重置，避免继承可交互关系同时保留长期外交投资回报。

**状态**: Accepted（2026-08-15，用户确认）

## 决策

1. **独立于既有口径**：探索外交加成新增固定 0.05 基础项与探索结盟累计项；ADR-0048 的有名派系结盟计数与范围不改。
2. **计数**：只统计探索发现势力的首次成功结盟；同一势力不重复计数，关系失效不回收。
3. **倍率**：当前周目未进入 `ended/infinite` 时探索外交贡献为 1.00；进入后为 `1.05 + 0.05 × 探索结盟累计次数`。该贡献与既有有名派系加成采用加法合并。
4. **资源边界**：覆盖所有资源产出，包括离线收益与资源型掉落；不放大兑换结果、消费返还或非资源奖励。
5. **生命周期**：累计次数跨 NG+ 保留，具体派系关系、探索进度及其他周目内外交状态继续按既有 NG+ 规则清空。

## 为什么

探索外交的长期价值需要在发现与结盟后持续体现，但不应改变既有有名派系加成口径，也不应让新周目前期绕过探索阶段获得终局收益。只保存累计投资而不保存关系状态，在保留长期成长的同时避免继承可交互外交状态。

## 后果

- 产出倍率需要区分当前周目探索阶段开关与跨周目累计次数。
- NG+ 存档迁移必须保留累计次数，并对旧档提供无累计次数的默认值。
- 既有 ADR-0048 的矿/能源/科技范围保持不变；新增探索外交贡献按“所有资源产出”口径处理。
