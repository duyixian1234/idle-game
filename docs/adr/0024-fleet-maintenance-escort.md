# 舰队维护软降级 + 护航返还锚定（防印钞）

舰队（能源消耗途径 + 防御系统）两条防印钞设计：① **维护费软降级**——能源 ≥ 总维护费 → 扣费运转；不足 → 不扣费、停摆，恢复供能自动重启（不惩罚、不负债、不自杀）；② **护航返还锚定**——护航远征的返还锚定「基础成本 + 远征费」（远征费 = 10 秒 × 能源净产出，随当期产出膨胀同步膨胀），energy 分支返还压低（0.2，投入能源返能源无意义）、mineral/tech 分支突出（0.75 / 0.02 tech-per-mineral）。

**状态**: Accepted（2026-08-07 定稿，fleet/fleet-dock-10）
**证据**: `src/engine/engine.ts:119-120`（软降级注释）；`src/engine/balance.ts:294-325`（舰队参数族 + ESCORT 常量）；commit `b0eac75` 前后 fleet 系列

## 背景

舰队是通关后的能源消耗途径与防御系统，若维护费硬扣，能源不足会瞬间清空舰队（惩罚过重、体验崩溃）；若护航收益不锚定产出，能源膨胀后期护航成为无限印钞机（投入 1 秒产出 → 返还 10 秒产出）。

## 决策

1. **软降级**：`applyFleetMaintenance` 判定能源是否 ≥ 总维护费——足则扣费运转，不足则**不扣费、停摆**（不负债）；供能恢复自动重启。停摆即战力归零，玩家有恢复动机但无惩罚性损失。
2. **战力公式**：`fleetPower = count × 1200 × (1 + 0.1 × militaryTechLv)`；`SHIP_POWER_BASE = 1200`（balance-sim 锚点：Lv1 船坞满编 3 艘 = 3600 ≥ 铁卫 70 强度 3500 → 可自动迎击；沃克斯 60 强度 3000 需 2 艘 + 科技 Lv3 才够——科技改变判定边界）。
3. **成本几何级数**：第 n 艘成本/维护 = base × `SHIP_GROWTH`(1.5)^(n-1)——满编 24 艘维护 2833/s（恒星阵列 Lv3+ 时代 ~26%），永不超过当期产出 30%（不破产）。
4. **护航返还锚定**：单艘远征费 = 10 秒 × 能源净产出（`ESCORT_ENERGY_SECONDS = 10`）；返还率 = 锚定（基础成本 + 远征费），energy 0.2 / mineral 0.75 / techPerMineral 0.02——投入越多、产出越高时成本与回报同步膨胀，**取舍永不失效**。
5. **收获倍率**：护航每艘 +1% 收获倍率（满编 24 艘 +24%），与科技收获倍率乘法叠加，只作用 resource 分支补偿。

## 为什么

- 软降级是「挂机友好」与「资源约束」的平衡：停摆（战力归零）是软性惩罚，不负债避免「回归瞬间破产」的挫败；恢复自动重启是幂等设计（无状态残留）。
- 返还锚定产出的动机与 post100 动态下限（ADR-0022）同构：**成本/回报锚定产出侧 → 相对价值跨周目不塌缩、不印钞**——护航是「溢出能源 → 探索收益」的转换器，锚定保证转换率恒定。
- 几何级数成本 + 维护占比上限（≤30%）保证舰队是「可负担的持续消耗」而非「一次买断的印钞机」。

## 后果

- `fleet: { count }` 存档仅存 count，船坞等级派生自 `buildings/upgrades.dock`，powered 为每 tick 判定不存档——避免派生状态落盘漂移（ADR-0005 原则）。
- 自动探索（护航偏好）随 NG+ 重置为默认关（舰队归零 → 护航自然失效），开关与偏好一并归零。
- 离线结算同样走软降级逻辑，离线期间能源不足舰队停摆、回归自动恢复——离线不惩罚。
