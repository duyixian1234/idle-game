# 军力容量科技通道：军械科技每级 +10% 容量（整体乘法）

> **⚠️ 修订（2026-08-08，[ADR-0036](./0036-ordinary-building-no-upgrade.md)）**：本 ADR 公式 `militaryCap = (100 + 200×军港×levelMultiplier(portLevel)) × ...` 中 `levelMultiplier(portLevel)` 项因 militaryPort 升级被砍而 **portLevel 恒 0**（`levelMultiplier(0)=1`），军港回 200/座线性。公式结构不变，但军港升级的 +50%/级乘法放大消失，军力容量等级放大从军港升级的 ×6（Lv10）缩到军械科技的 ×1.5（Lv5）。决策 1-4（军械科技通道本身）仍有效；后果中"军港仍是容量主引擎"语义不变且更纯粹（数量轴唯一引擎）。`COERCION_UNLOCK_MILITARY_CAP=5000` 仍由 25 军港达成，不变。

军力容量公式 `militaryCap = ⌊(100 + 200×军港×(1+0.5·lv)) × (1+永久+声望)⌋` 此前无任何科技扩容通道——容量只有「军港数量流」一条增长路径，与舰队战力的科技指数增长（满配 ×4.5）脱节。决策：**军械科技（militaryTech）每级 +10% 容量，整体乘法叠加**（`×(1 + 0.1×militaryTechLv)`），Lv5 = +50%。

**状态**: Accepted（2026-08-08 定稿，grill 三轮 Q3/Q5/Q6）
**证据**: `src/engine/production.ts:29`（militaryCap）；`src/engine/balance.ts:185-190`（MILITARY_BASE_CAP / MILITARY_PORT_CAP）；`src/engine/data.ts:431`（militaryTech）；`.scratch/fleet-power-exploration/`（战力杠杆）

## 背景

军力是唯一有容量约束的资源（满员时兵营产出截断）。容量决定攻占可投入上限（`p = min(1, invest/guard)`）与探索派遣军力消耗（`mCap×2%` clamp 1000）。但军事科技（军械 Lv5 / 星舰 Lv20）只强化「战力」不强化「容量」——「能打」与「装得下」在科技侧脱节：玩家堆军事科技后容量仍是瓶颈，军港数量流成为唯一解。

## 决策

1. **整体乘法**：`militaryCap = ⌊(100 + 200×军港×levelMult) × (1+永久+声望) × (1 + 0.1×militaryTechLv)⌋`——与永久加成/声望加成同构（全部乘法叠加），实现最自然。
2. **新常量**：`MILITARY_CAP_TECH_PER_LEVEL = 0.1` 进 balance.ts 根因子区（`/ 生产 / 军力` 分组）。
3. **复用军械科技线**：不新增独立容量科技（新增 TechDef + 成本曲线 + 平衡模拟的复杂度，收益与复用相近）。军械科技从「军力产出提升」扩展为「军力产出 + 容量」双效果。
4. **排除的候选**：加法口径（`+20×militaryLv`）引入第三套加法体系，与乘法家族不一致（否决）；独立「轨道装甲」新线高复杂度（否决）。

## 为什么

- 乘法叠加与既有 `(1+永久+声望)` 同构：容量 = 基础 × 累计乘数，调参只动根因子 `MILITARY_CAP_TECH_PER_LEVEL`（ADR-0006）。
- +50% 上限（Lv5）远低于军港数量流（50 座军港 = +10000 容量）：科技通道是「温和松绑」，军港仍是容量主引擎——「容量是约束」的玩法语义不破。
- 军械科技单线双回报（战力 ×1.5 + 容量 ×1.5）：一条军事科技线同时解决「能打」与「装得下」，玩家投入产出比清晰。

## 后果

- **胁迫外交解锁提前**：`COERCION_UNLOCK_MILITARY_CAP = 5000`。无科技需 25 座军港；Lv3 军械（+30%）→ ≈19 座、Lv5（+50%）→ ≈17 座。正面效果：胁迫线（通关后深度玩法）更早可玩，内容前置不破坏节奏。
- **探索派遣军力联动被 clamp 吸收**：`mCap×2%` 基数抬高，但 `clamp 1000` 封顶需 mCap > 50,000（≈166 座军港，post100 后置锁死范围内实际到不了）——派遣军力消耗实际不随军械等级漂移，无副作用。
- **balance-sim 补断言**：① `Lv5 军械 + 25 座军港 → 容量 = 7,650 ≥ 5000`（胁迫解锁早于纯军港路径 ~32%）；② 探索派遣军力在容量膨胀下仍 ≤1000（clamp 有效，断言不随军械等级漂移）。
- 军力容量成为「数量流（军港）× 乘数流（永久/声望/科技）」双轴：上限增长从纯线性变为线性×线性，高周目容量相对产出不再塌缩。
