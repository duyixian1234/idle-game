# 唯一大件对称增长 ×2/级 + NG+ 遗产折算

星系间建筑与终局建筑（星港矿场/聚变恒星阵列/星海智库/星环冶炼场/跃迁枢纽）是**唯一大件**（count 恒 1，禁重复建造、禁 bulk）：升级成本与产出**对称 ×2/级**（`UNIQUE_UPGRADE_GROWTH = 2`，maxLevel=10，成本总投入 = 首购 ×1023，收益 ×1024）。NG+ 时等级 ×1.5%/级折算全产出永久加成（`NG_PLUS_MEGASTRUCTURE_BONUS`）。

**状态**: Accepted（2026-08-06 定稿，interstellar-buildings；2026-08-07 双轨开放见 ADR-0010）
**证据**: `src/engine/balance.ts:280-292`（UNIQUE_UPGRADE_GROWTH 等）；`.scratch/interstellar-buildings/spec.md`（决策 55/58、校准结论）；commit `cd20f95` 前（v7 存档）

## 背景

普通建筑成本公式（`buyCost × P × 0.5 × count / levelMultiplier`，ADR-0021）依赖 **count 增长**——唯一建筑 count 恒 1，套用该公式会导致升级成本递减（「升级越多越便宜」的死局）。且通关后需要「下一数量级」的产出跃迁层与终局目标。

## 决策

1. **独立公式**：唯一大件升级成本 `baseCost × 2^level`、产出 `base × 2^level`——**不复用** count 折算公式；与普通建筑 `levelMultiplier`（线性）并存为两条产出分支。
2. **对称增长性质**：成本 ×2/级 与收益 ×2/级对称 → 末级成本 ≈ 累计收益（首购 ×1023 投入 vs ×1024 收益）——「海量但可达」，避免末级成本远超累计收益的数学死局。
3. **解锁链**：星港（第 5 星球 + 深层钻机 ≥6 台）→ 恒星（通关后 + 星港 ≥1）→ 智库（通关后 + 恒星 ≥1）→ 终局建筑（通关后 + 三星系间各 ≥1）；深层钻机数量门槛 = **建筑数量 ≥6**（`buildings.deepDrill ≥ 6`，ADR-0039——原「深钻满级 `upgrades.deepDrill ≥ Lv10`」在 ADR-0036 砍普通升级后无法达成，2026-08-08 改为数量前置，6 台 = 48/s 等效原 Lv10 产出天花板）。
4. **维护费硬扣**：恒星阵列消耗矿产维护（20 矿/s ×2^level），走独立结算**不参与能源打折**（与 `consumes` 能源语义隔离）——能源/矿产链真实约束。
5. **bulk 屏蔽**：唯一大件禁用一键买满/升满，只保留单级操作——不绕过逐级投入的海量成本语义。
6. **NG+ 遗产**：等级 ×1.5%/级 → `permanentBonuses.production`（双轨后为两座等级之和，ADR-0010 决策 4）——海量投资跨周目有残余价值。

## 为什么

- 对称 ×2/×2 的数学优雅：成本投入 ∑2^L = 2^10−1，收益 2^10，末级边际成本恰被末级边际收益吸收——「海量」与「可达」同时成立，无需 clamp。
- 独立公式避免「count=1 时成本递减」的公式病——普通建筑公式与唯一建筑公式的边界就是 count 语义的边界。
- 维护费独立结算使「矿→能源→全局产出」闭环真实：满级冶炼场 1000 能源/s ≈ 满级恒星阵列产出，能源链是约束而非摆设。

## 后果

- balance-sim 校准（贪心最短等待优先，外生科技 2000/s 保守口径）：冶炼场 Lv10 总耗时 15.3 天 ≈ 2.2 周（玩家存量建筑/探索天体/NG+ 加成加速后落回 1-2 周目标）；能源闭环 ✓；维护费占比 4% ≤ 5%——四项硬约束全过，数值无需校准。
- 终局建筑是唯一「成本不随产出缩放」的例外（不挂动态下限）——刻意：终局目标就该是静态海量。
- 跃迁枢纽无升级（恒 0 级，贡献 0 遗产）——探索流路线不产出永久加成，与建设流形成路线差异（ADR-0010）。
