# 非唯一建筑 100 台后置成本曲线：动态下限挂净产出，防高周目塌缩

非唯一建筑（miner/solar/lab/refinery/deepDrill/barracks/militaryPort）在 **100 台之后**启动后置成本曲线：超阈每 1 台 ×`POST100_GROWTH`（1.05，150 台 ×12、200 台 ×132、300 台 ×1.7 万），且买入成本**动态下限 = 3 秒 × 当前净产出**（`POST100_BUY_TARGET_SECONDS = 3`）——成本锚定产出侧，自动跟随 NG+ 永久加成/科技/冶炼场等全部乘数，高周目（×64/×1024）相对价格不塌缩。

**状态**: Accepted（2026-08-07 定稿，grill 三轮 + balance-sim 校准）
**证据**: `src/engine/balance.ts:42-49`（POST100 常量）；`.scratch/post100-cost-curve/spec.md`；commit `0b8b99b`（实现）

## 背景

后期每秒产出达千亿级（实测约 7000 亿/s）时，普通建筑 100+ 台后买入/升级成本相对产出几乎为零（实测 <0.1 秒产出）——购买与升级失去决策摩擦。且成本不随任何产出乘数缩放：×64/×1024 高 NG+ 会把相对价格压到 1/64~1/1024，成本曲线名存实亡。

## 决策

1. **阈值口径**：每种建筑各自计 100，不合计、不分组；≤100 台曲线完全不变（`excess == 0` 时 `postFactor = 1`、无动态下限）。
2. **动态下限**：`buyCost_r = floor(max(staticCost_r, dynamicFloor_r) × postFactor)`，`dynamicFloor_r = 3 × netProduction_r`（仅产出 > 0 的资源项）；每个成本资源独立取 max，产出为 0/负跳过动态下限回退静态。
3. **升级继承**：升级公式结构不动（`buyCost × count × (1 + 0.15×level)`，ADR-0021），因内部调用新 `buildingCost` 自动继承后置因子与动态下限——100 台阈值上升级自然落在 ≈5 分钟产出（3s × 100）。
4. **陡度校准**：`POST100_GROWTH = 1.05` 初值经 balance-sim 验证「跨周目相对价格比值 1.00」保持定稿；200 台买入 ≈6.6 分钟、升级 ≈21.9 小时，摩擦显著但不死档。
5. **存量档即时套用**：不做豁免、不 clamp 台数；老档超额台数下次购买/升级直接变贵（动态下限挂当前产出，高 NG+ 存档不会瞬间死档）。

## 为什么

- 动态下限挂 `netProduction` 而非固定指数/仅 NG+ 加成：**产出膨胀时成本同步膨胀**，相对价格（秒产出）跨周目同阶——这是「高周目不塌缩」的结构性保证。
- 保留升级公式结构 = 保留 ROI≈P=2 的交替决策（count=100 时升级成本 ≈ count×买入，收益 0.5×全台产出，成本/收益 ≈ 2×，与 P=2 一致）。
- 存量档即时套用避免「两套价格体系」的迁移复杂度——成本是纯函数计算字段，改公式老档自动套新价，零迁移（ADR-0005 分级策略的受益者）。

## 后果

- 唯一大件、舰队、科技曲线明确不在范围（各自独立曲线，ADR-0023）。
- bulk（买满/升满）逐次调用 buildingCost，动态下限随模拟态 netProduction 实时重算（买越多→产出涨→下限涨）——自调节且循环必终止。
- 相对价格显示（ADR-0016 timeToSave）自动反映新曲线：100 台阈值点从「≈N 秒」跳升到「≈N 分钟」。
