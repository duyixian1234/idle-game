# 科技点经济出口演进：兑换引入 → 升级膨胀 → 兑换移除，出口重定向

科技点（tech）的经济角色历经演进：初版矿物 100:1 单向兑换（引入，`cbb283f`）→ 科技升级成本增长 1.5→1.7（`f6d23d8`，满级需求 17 万→131.7 万，升级成为通关期持续目标）→ 轨道工厂转换 30%→15%（`1053bd4`，模拟显示科技点过剩 ×32.7，减半收敛）→ **兑换机制移除**（`24de5c7`）——科技点出口从「兑换矿物」重定向到「升级 + 技术共享 + 事件科技分支 + 攻占科技消耗」等玩法出口。

**状态**: Accepted（2026-08-05 定稿 tech-upgrade，2026-08-07 兑换移除）
**证据**: commit `cbb283f`/`f6d23d8`/`1053bd4`/`6514f11`（技术共享）/`54e30f2`（事件科技分支）/`24de5c7`（移除兑换）；`src/engine/balance.ts:38-40`（TECH_UPGRADE_GROWTH）

## 背景

科技点作为第三资源必须有「消耗出口」，否则产出科技点失去意义（模拟显示过剩 ×32.7）。初版出口是矿物兑换（100:1），但兑换是「科技点 → 矿物」的无限转换器：矿物短缺时兑换即等价于「矿物直接产出」，把三资源经济压扁成两资源，且兑换与产出比失衡时成为印钞通道（先攒科技点，缺矿就兑换）。

## 决策

1. **升级成本膨胀**：`TECH_UPGRADE_GROWTH = 1.7`（cost(lv) = base × 1.7^(lv−1)，满级 5 项合计 42.8 万科技点）——升级成为通关期持续目标，科技点有主出口。
2. **轨道工厂收敛**：转换比例 30%→15%（模拟显示科技点过剩 ×32.7，减半后收敛；机制描述与断言同步）。
3. **出口重定向**：移除「科技点 → 矿物」兑换（100:1）；替代出口为——**科技升级**（主）、**技术共享**（20,000 科技点换好感 +15，外交出口）、**事件科技分支**（陨石雨防护罩采集翻倍 / 虫族警报神经干扰用科技点替代矿物清剿）、**威慑科技点成本**（技术优势语义）、**攻占/探索相关科技消耗**。
4. **无印钞闭环**：所有科技点出口都是「消耗品」（升级提升产出但成本指数膨胀；技术共享/事件分支是一次性消费），不存在「科技点 → 资源 → 科技点」的循环增益。

## 为什么

- 兑换是「无限转换器」，破坏三资源经济的独立性；移除兑换后，科技点只能通过玩法出口消耗，各资源保持独立的经济角色（矿物=扩张，能源=维护，科技=加速）。
- 升级成本 1.7 倍指数增长让科技点「永远不够花」（满级需求 42.8 万 vs 产出），升级线有持续目标感——这是 idle-game 双升级线（建筑 count 线 + 科技 level 线）的数值基础。
- 出口重定向让科技点深度参与外交（技术共享）、事件（科技分支）、军事（威慑）——资源不再单维，跨系统联动是「科技点有存在感」的结构保证。

## 后果

- 科技升级线（base × 1.7^L）在 balance-rework 明确「不卷 count，已平衡，维持现状」（ADR-0021 Out of Scope）。
- 科技点兑换移除后，`TECH_EXCHANGE_RATE` 常数退役，balance.ts 中不留死常量。
- 事件/外交的科技点消耗需维持「与科技产出同量级」的锚定（技术共享 20,000 ≈ 满级前主力产出期的合理负担），防通胀或过剩。
