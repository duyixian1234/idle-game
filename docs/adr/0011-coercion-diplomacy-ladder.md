# 胁迫外交三级阶梯：勒索 → 条约 → 臣服 + 三重赎罪，解锁条件双通道解耦

在好感/威慑之外新增**胁迫外交**体系，三级阶梯递进：勒索（军力门槛，即时矿物收益 + 好感代价）→ 进贡条约（12h 持续矿物税，threat 到期反弹）→ 臣服（锁定军力 + 持续高额税，叛变风险）；配「三重赎罪」退出通道（赔偿递增，赎罪后永久禁胁迫 + 结局文本分支）。解锁条件与 raid 遭遇**解耦**：军力上限 ≥ 5000 或 遭遇过 raid 任一即永久解锁。

**状态**: Accepted
**日期**: 2026-08-07（v13 存档）
**证据**: `src/engine/types.ts:172-198`（FactionState v13 字段）；`src/engine/balance.ts:91-143`（胁迫参数族）；commit `9927ecf`（三级阶梯）、`ef46582`（解锁条件解耦）

## 背景

外交系统（贸易/结盟/威慑）是唯一的外交玩法，军力资源在结盟后失去用途；需要一条「军力 → 收益」的黑暗路线，同时避免胁迫成为无脑印钞。初版解锁依赖「遭遇过 raid」，但 raid 是低概率事件——玩家可能通关都遇不到一次，胁迫内容完全不可达（结构性枯竭：威胁源无被动增长）。

## 决策

1. **三级阶梯**：勒索（`EXTORT_MILITARY_PCT` 0.4 军力门槛，收益基准 ≈ 贸易 5 次累计，成本 ×1.5^extortCount 递增）→ 条约（12h 固定时长，5.56 矿/s 持续税，`threat` 到期 +10 反弹）→ 臣服（favor ≤ 20 + threat ≥ 70 + 军力 60% 门槛，锁定 25% 军力不可他用，11.1 矿/s 税，threat 爆炸即叛变）。阶梯内部**互斥递进**，每级解锁下一级的「谈判筹码」。
2. **三重赎罪**：赔偿金基准 ×1.5^extortCount 递增，赎罪期 12h（期内贸易好感 ×1.5）；完成后 `atoned = true` 永久禁胁迫 + 专属成就；`everCoerced` 跨周目保留驱动结局文本分支（「征服者统一」）。
3. **解锁双通道**：`COERCION_UNLOCK_MILITARY_CAP = 5000`（军力上限达标，对齐成就 militaryCap5k 语义）∨ raid 遭遇，任一满足即解锁、`storyFlags` 跨周目永久保留；首次解锁播报叙事（幂等）。
4. **全参数进 balance.ts**：勒索/条约/臣服/赎罪全部数值（门槛、成本、税率、时长、递增）集中声明，标注「grill Qn 定稿」——胁迫是数值最重的域，调参单点。

## 为什么

- 三级阶梯把「军力」变成可持续剥削资产，同时递增成本 + 叛变风险阻止印钞：勒索收益 ×1.5 递增而好感 -30，无限勒索必然崩盘，迫使玩家进入赎罪/臣服循环。
- 解锁双通道解决「raid 结构性枯竭」：军力阈值给了确定可达的解锁路径，raid 给了早期遭遇玩家的提前解锁。
- 赎罪是「黑暗路线退出机制」——胁迫不是单向沉沦，赎罪后重回外交线且获得结局叙事分支。

## 后果

- `FactionState` v13 新增 7 个可选胁迫字段，旧档迁移补默认值（migrateV12ToV13）。
- 贡税并入 `productionReport` 离线自动结算（tick 与 settleOffline 共用），自动外交（ADR 见 diplomacyAuto）只覆盖贸易/技术共享，**胁迫类一律手动**——胁迫是玩家主动行为，不自动化。
- 结局判定文本按 `everCoerced` 分支（征服者统一 vs 星系统一联邦）——胁迫历史成为叙事资产。
