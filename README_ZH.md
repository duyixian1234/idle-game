# 深空拓荒 · 星系统一联邦

> 一款完全运行在浏览器里的文本式太空采矿挂机游戏。

**语言 / Language：** [English](README.md) · **简体中文**

从一颗荒芜星球起步，建造自动化采矿经济，研发科技，在五颗星球间扩张，通过外交与四个派系周旋，最终达成 **「星系统一联邦」** 结局——通关后还有无限模式与 NG+ 周目在等待。

## 特性

- **挂机核心**：建筑离线也在产出矿物/能源/科技点；离线收益按真实时间差结算（8 小时封顶，跃迁枢纽可放宽至 12 小时）。
- **四种资源**：矿物 `◆`、能源 `⚡`、科技点 `◎`、军力 `⚔`。
- **建造与科技**：可多次购买建筑（采矿机/太阳能板/实验室/精炼厂/深层钻机/兵营/军港）走数量维度；唯一大件与科技走等级维度（`×2`/级），彻底消除"数量 × 等级"耦合。
- **5 颗星球，5 种机制**：每解锁一颗星球都引入新机制——轨道合金冶炼、引力井衰减、风暴批量生产、曲率时间加速……直至终局母星·曙光。
- **派系外交**：与铁卫同盟、圣光议会、天鹅贸易联盟、沃克斯矿业集团及生成派系贸易/结盟/胁迫（勒索 → 进贡条约 → 臣服），自动外交模式让挂机也能推进。
- **攻占与舰队**：兵营训练军力、军港提升容量上限，自动攻占生成目标，研发劫掠战术；舰队能源不足时软降级停摆、恢复供能自动重启。
- **探索派遣**：向程序生成天体派遣舰队，发现产出型天体，解锁终局工程路线。
- **终局工程**：通关后开放三条独立路线——星环冶炼场（建设流，全局产出 ×2/级）、跃迁枢纽（探索流，+3 槽/收获 ×4/离线 12h）、虫洞（探索线延伸 + 军力线），三座皆可建、效果叠加。
- **无限模式与 NG+**：通关后继续挂机，或开启新周目继承科技点、派系图鉴与永久加成。
- **双语界面**：中文 / English，自动跟随浏览器语言，可在设置中切换。
- **PWA 可安装**：Service Worker 预缓存全部产物形成离线可加载外壳，自托管字体，响应式适配移动端。
- **存档自由**：IndexedDB 每 5 秒自动保存，JSON 导出/导入方便分享，也可一键重置。
- **终端文本风 UI**：顶部资源条 + 中央日志流（可筛选）+ 分页操作面板，typewriter 打字机叙事，WebAudio 合成音效一键静音。

## 快速开始

环境要求：Node.js 22+ 与 pnpm 10。

```bash
pnpm install
pnpm dev
```

构建与测试：

```bash
pnpm typecheck   # TypeScript 类型检查
pnpm build       # tsc --noEmit && vite build → dist/
pnpm preview     # 预览生产构建
pnpm test        # Vitest 单元测试
pnpm test:e2e    # Playwright 端到端测试
```

## 玩法指引

1. **在荒芜星 P-01 造第一台采矿机**——矿物开始自动累积。
2. **平衡经济**：太阳能板产能源、实验室产科技点；精炼厂用能源换更多矿物（能源不足时产能按比例打折）。
3. **研发科技**：解锁新建筑（如深层钻机）与各类产出倍率线。
4. **达标解锁星球**：达到资源门槛解锁下一颗星球，每颗星球的新机制都会重塑你的经济形态。
5. **接触派系**（轨道工厂站解锁后登场）：通过贸易、结盟或胁迫提升好感度。
6. **统一星域**：与全部派系结盟或好感达标达成结局，随后深入终局内容。

## 技术栈

- **语言/构建**：TypeScript、Vite、vite-plugin-pwa
- **引擎**：纯 TypeScript、零 DOM 依赖（资源产出、科技、外交、事件、探索、攻占、舰队、离线结算、存档序列化）
- **UI 层**：在不可变引擎快照之上做 DOM 渲染，tick 与 render 同源共享同一状态引用
- **持久化**：IndexedDB 自动存档 + JSON 导出/导入
- **i18n**：`src/i18n/zh.ts`（真源）+ `src/i18n/en.ts`
- **测试**：Vitest（引擎 seam + jsdom UI 冒烟）、Playwright（语义化 `data-*` E2E 断言）
- **CI**：GitHub Actions——push/PR 自动跑 typecheck、build、PWA 构建检查与单元测试

## 目录结构

```
src/

            # diplomacy、events、exploration、conquest、fleet、offline、save、ngplus ...

  i18n/     # 中英文文本资源

```
